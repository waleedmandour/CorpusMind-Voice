# كوربس مايند فويس — دليل المستخدم (العربية)

**الصفحة ١ من ٢ · التثبيت والتسجيل وخط المعالجة ذي الخطوات الست**

«كوربس مايند فويس» هي الأداة الصوتية المكمّلة لـ [CorpusMind](https://waleedmandour.org/projects/CorpusMind/)، بيئة البحث المحلية لتحليل الcorpus وخطاب الوسائط المتعددة. تُحوِّل التسجيلات (MP3 وMP4 وM4A وAAC وOGG وOPUS وWAV وFLAC وWEBM وWMA وAMR و3GP وAIFF) أو مدخل الميكروفون المباشر إلى corpus لغوي مُعلَّم على جهازك أنت، ثم تحلِّله تحليلًا أكاديميًا. لا حساب مطلوب، ولا يُرفع أي ملف، ولا تُستدعى أي واجهة سحابية أبدًا — نموذج الخصوصية مطلق بالتصميم. يشرح هذا الدليل (صفحتان) التثبيت وخط المعالجة الست ومسار التحرير، بمصطلحات متوافقة مع ما ورد في [موقع المشروع](https://waleedmandour.org/projects/CorpusMind/).

## ١. التثبيت

تعمل نسخة الويب في أي مكان يعمل فيه Node.js أو Bun: نفّذ `bun install` ثم `bun run db:push` ثم `bun run dev` وافتح `http://localhost:3000`. يمكن تثبيتها كتطبيق **PWA** من شريط العنوان (أو زر «تثبيت التطبيق») — وعلى الهاتف أو اللوح يتيح لك الـPWA **التسجيل والتحليل أينما كنت**، كله على الجهاز نفسه. أما **إصدارات سطح المكتب** الأصلية — ويندوز ‏(.exe / .msi) وماك ‏(Apple Silicon وIntel بصيغة .dmg) ولينكس ‏(.deb / .AppImage) — تُرفق بكل إصدار على GitHub، وتحمل خادمها الخاص دون حاجة لتثبيت بايثون. لمخرجات بحثية كاملة ثبّت عامل بايثون: `pip install -r python/requirements.txt` (faster-whisper وParselmouth). كما يمكن تثبيت Montreal Forced Aligner اختياريًا لحدود صوتية على مستوى المقاطع (`conda install -c conda-forge montreal-forced-aligner` ثم تنزيل النماذج والقواميس `arabic_mfa` / `english_us_arpa`).

تستقبلك عند أول تشغيل **نافذة ترحيب** من ثلاث صفحات قصيرة (عربي/إنجليزي) تشرح التطبيق ونموذج الخصوصية دون اتصال والبداية السريعة؛ ويوجد في الترويسة مبدّل **المظهر الفاتح / الداكن / حسب النظام**.

## ٢. النماذج والحِزم والعتاد

افتح تبويب **الإعدادات والتشخيص** قبل أول مهمة.

- **النماذج والحِزم** — نزِّل أي حجم من نماذج Whisper عند الطلب: ‏`tiny` ‏(٧٥ ميجابايت) و`base` ‏(١٤٥) و`small` ‏(٤٨٤) و`medium` ‏(١٫٥ جيجابايت) و`large-v3` ‏(٣٫١ جيجابايت، موصى به). تُخزَّن النماذج في مجلد بيانات التطبيق الخاص، وتبقى بعد إعادة التشغيل والتحديثات، وتُعاد الاستفادة منها دون اتصال؛ التنزيلات قابلة للاستئناف وبشريط تقدّم حيّ. ويمكنك حذف أي نموذج لاستعادة المساحة.
- **العتاد والتشخيص** — تقرأ اللوحة المعالج والذاكرة وكرت NVIDIA (عبر `nvidia-smi`). بوجود CUDA يعمل التفريغ بدقة INT8-float16 على كرت الرسوميات؛ وبدونه يُظهر التطبيق تحذيرًا صريحًا بأن المعالجة ستعود إلى المعالج (INT8) وقد تستغرق ضعف الزمن الحقيقي تقريبًا. يمكنك أيضًا تثبيت الجهاز لكل مهمة من تبويب **الاستوديو** (تلقائي / معالج / كرت رسوميات) واختيار نموذج Whisper لكل مهمة.
- **النموذج اللغوي المحلي** — يُكتشف Ollama (المنفذ ١١٤٣٤) وLM Studio (المنفذ ١٢٣٤) تلقائيًا بالأسلوب نفسه المتبع في CorpusMind الأم (‏127.0.0.1 + localhost + ‏`OLLAMA_HOST`)؛ وعلى سطح المكتب يمكن للتطبيق تشغيل `ollama serve` نيابة عنك.

## ٣. التسجيل والمعالجة (الخطوات الست)

1. من تبويب **الاستوديو**، أفلت ملفًا أو انقر منطقة الإفلات للاختيار؛ أو انقر **التسجيل من الميكروفون** لالتقاط الصوت المباشر (اضغط «إيقاف التسجيل» لرفع التسجيل). على سطح المكتب يطلب التطبيق إذن الميكروفون مرة واحدة (ماك) أو يمنحه تلقائيًا (ويندوز)؛ وعلى متصفحات الهاتف تحافظ سلسلة بدائل الترميز (webm/opus ← mp4/aac ← ogg) على عمل التسجيل في كل مكان.
2. اختر **اللغة** (الإنجليزية، العربية — المصرية عامية، العربية — الفصحى) و**جهاز المعالجة** و**نموذج Whisper**.
3. انقر **بدء المعالجة**. يُعرض التقدّم لكل مرحلة مباشرةً من طابور المهام المحلي:

| # | المرحلة | ما يحدث |
|---|---------|---------|
| ١ | **الإدخال والمعالجة المسبقة** | فكّ الحاوية إلى WAV أحادي ١٦ كيلوهرتز (PyAV/pydub) |
| ٢ | **التفريغ ASR** | faster-whisper بالنموذج المختار بدقة INT8؛ طوابع زمنية ودرجة ثقة لكل كلمة |
| ٣ | **المحاذاة القسرية** | تُدقّق MFA حدود الكلمات والمقاطع (عند تثبيتها) |
| ٤ | **السمات الإيقاعية** | Praat عبر ParSelmouth: النبرة الأساسية (٥٠–٤٠٠ هرتز)، الشدة، الجيتر، الشيمر، HNR |
| ٥ | **اضطرابات الكلام** | توقفات > ٢٠٠ ملي ثانية، حشو (يعني، آه، إيه، um، uh)، تكرار، بدايات خاطئة، مقاطعات، مدّ أصوات |
| ٦ | **المخرجات المنظمة** | SQLite (٣ جداول) + JSON + TEI/XML محليًا |

إذا لم يكن عامل بايثون مثبتًا، يعمل **محرك المحاكاة** بدلًا منه — نفس المراحل الست مع corpus تجريبي — مع وسم المهمة بـ«محاكاة» حتى لا تختلط البيانات التجريبية بالتفريغات الحقيقية.

## ٤. تصحيح التفريغ (محرر الثقة الملوَّنة)

افتح تبويب **محرر التفريغ**. تحمل كل كلمة درجة ثقة ASR كلون خلفية: **أخضر ≥ ٠٫٨٥**، **كهرماني ٠٫٦٠–٠٫٨٥**، **أحمر < ٠٫٦٠** — ابدأ بمراجعة الكلمات الحمراء. انقر أي كلمة لتصحيحها: يحفظ التعديل ويوسم الكلمة بأنها «معدَّلة» ويُدرج الجملة في **إعادة محاذاة لهذه الجملة فقط**، فلا تُعالَج الملفات كلها من جديد لإصلاح كلمة واحدة. تعرض كل جملة أيضًا الاضطرابات المكتشفة (عدد التوقفات، الحشو، التكرار، البدايات الخاطئة، المقاطعات، المدّ) وملخص الإيقاع (متوسط/أدنى/أقصى نبرة، الشدة، الجيتر، الشيمر، HNR). وفي أسفل التبويب صف **حفظ على الجهاز** لكتابة JSON / CSV / TEI/XML / SQLite متى احتجت.

## ٥. التحليل اللغوي (جديد في الإصدار ١٫١٫٠)

يحسب تبويب **التحليل اللغوي** تقريرًا أكاديميًا كاملًا محليًا — لا يُرفع شيء. ثمانية أقسام:

- **نظرة عامة** — الكلمات والأنواع ونسبة النوع/الرمز ومعدل الكلام (كلمة/دقيقة) والجمل والكلمات الأحادية الورود وتوزيع الثقة.
- **التكرارات** — قائمة الكلمات بالتكرار والمعدل لكل ألف وتوزّع **DP** ‏(Gries) مع مرشِّح كلمات الوظائف ورسم بياني.
- **السياق KWIC** — كونكوردانس بنافذة سياق قابلة للضبط ومطابقة حالة الأحرف والطوابع الزمنية؛ قابل للتصدير.
- **المفاتيح** — اللوغاريتم الاحتمالي **G²** وحجم الأثر **LogRatio** ‏(Hardie 2014) مقابل جلساتك الأخرى، أو مقابل مرجع مدمج لكلمات الوظائف عند وجود جلسة واحدة.
- **التجمّعات والمتتاليات** — مقاييس ترابط الثنائيات (**MI** و**t-score** و**logDice**) مع أفضل الثنائيات والثلاثيات والرباعيات.
- **الثراء اللغوي** — **MATTR** (نافذة ٥٠) و**MTLD** (≥ ٠٫٧٢) غير الحساسين لطول النص، إضافة إلى TTR و**الكثافة المعجمية**.
- **القراءة** — سهولة قراءة فليش ومرتبة فليش–كينكايد (للإنجليزية)، ومؤشر **LIX** المحايد لغويًا ونسبة الكلمات الطويلة.
- **الكلام والإيقاع** — معدلات الاضطراب لكل ١٠٠٠ كلمة حسب النوع وإحصاءات التوقفات وتجميعات Praat الإيقاعية (متوسط/مدى النبرة، الشدة، الجيتر، الشيمر، HNR).

كل جدول يُحفظ CSV، والتقرير الكامل يُحفظ JSON.

## ٦. البيانات الوصفية للcorpus (ترويسة TEI)

من تبويب **البيانات الوصفية** صِف الجلسة: العنوان، اسم المتحدث أو اسمه المستعار، اللهجة، الجنس، العمر، تاريخ ومكان التسجيل، النوع، الرخصة، وملاحظات حرة. تُضمَّن هذه الحقول في `<teiHeader>` لكل ملف محفوظ، وهي نفسها الحقول التي يتوقعها CorpusMind عند الاستيراد — راجع فصل البيانات الوصفية في [موقع المشروع](https://waleedmandour.org/projects/CorpusMind/). يحمل التبويب أيضًا صف **حفظ على الجهاز** (JSON / CSV / TEI/XML / SQLite). على أي جهاز فيه CorpusMind مثبت، يفتح زر **تشغيل CorpusMind** في الإعدادات والتشخيص التطبيق المكمّل مع هذا الcorpus جاهزًا للبحث.

## ٧. المساعد الذكي المحلي وأدواته (اختياري)

يتحدث تبويب **المساعد** مع نموذج *محلي* عبر **Ollama** ‏(`http://127.0.0.1:11434`) أو **LM Studio** ‏(`http://127.0.0.1:1234`) — مثلًا: «اذكر الجمل التي فيها أكثر من كلمة حشو». شغِّل Ollama مرة بأمر `ollama serve` ونزِّل أي نموذج (`ollama run llama3.1`)، أو حمِّل نموذجًا في LM Studio؛ واختر النموذج من التبويب أو من الإعدادات. ثلاث أدوات للتفريغ الحالي تعمل عبر النموذج المحلي نفسه: **تلخيص** و**معاينة دون حشو** و**اقتراح وسوم موضوعية**. إن لم يكن أي مزوِّد متاحًا، تخبرك اللوحة بذلك ولا تستعوض أبدًا بخدمة سحابية.

## ٨. حل المشكلات

| العَرَض | الحل |
|---------|------|
| المهمة موسومة «محاكاة» | عامل بايثون غير مثبت → `pip install -r python/requirements.txt` |
| «MFA skipped» في المرحلة ٣ | اختياري: ثبّت MFA والقواميس (انظر §١) |
| «لم يُكتشف كرت NVIDIA» | طبيعي على الأجهزة بلا كرت؛ يُستخدم وضع المعالج INT8 |
| نموذج Whisper غير موجود في الاستوديو | الإعدادات والتشخيص → النماذج والحِزم → **تنزيل** |
| زر الميكروفون لا يعمل | اسمح بالوصول من المتصفح/النظام أو ارفع ملفًا؛ التسجيل يتطلب HTTPS أو localhost |
| المساعد غير متاح | شغِّل `ollama serve` أو حمِّل نموذجًا في LM Studio (المنفذ ١٢٣٤) ثم أعد فتح التبويب |
| «اختفى» نموذج منزَّل | لا يمكن ذلك — النماذج تبقى في مجلد بيانات التطبيق؛ تحقق من المسار المعروض في الإعدادات |
