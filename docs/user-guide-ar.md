# كوربس مايند فويس — دليل المستخدم (العربية)

**الصفحة ١ من ٢ · التثبيت والتسجيل وخط المعالجة ذو الخطوات الست**

«كوربس مايند فويس» هي الأداة الصوتية المكمّلة لـ [CorpusMind](https://waleedmandour.org/projects/CorpusMind/)، بيئة البحث المحلية لتحليل الcorpus وخطاب الوسائط المتعددة. تُحوِّل التسجيلات (MP3 وMP4 وWAV وM4A وWEBM وOGG وFLAC) أو مدخل الميكروفون المباشر إلى corpus لغوي مُعلَّم على جهازك أنت. لا حساب مطلوب، ولا يُرفع أي ملف، ولا تُستدعى أي واجهة سحابية أبدًا — نموذج الخصوصية مطلق بالتصميم. يشرح هذا الدليل (صفحتان) التثبيت وخط المعالجة الست ومسار التحرير، بمصطلحات متوافقة مع ما ورد في [موقع المشروع](https://waleedmandour.org/projects/CorpusMind/).

## ١. التثبيت

تعمل نسخة الويب في أي مكان يعمل فيه Node.js أو Bun: نفّذ `bun install` ثم `bun run db:push` ثم `bun run dev` وافتح `http://localhost:3000`. يمكن تثبيتها كتطبيق **PWA** من شريط العنوان (أو زر «تثبيت التطبيق») لتعمل الواجهة دون اتصال لاحقًا. أما **إصدارات سطح المكتب** الأصلية (ويندوز وماك ولينكس) تُرفق بكل إصدار على GitHub، وتحمل خادمها الخاص دون حاجة لتثبيت بايثون. لمخرجات بحثية كاملة ثبّت عامل بايثون: `pip install -r python/requirements.txt` (faster-whisper وParselmouth). كما يمكن تثبيت Montreal Forced Aligner اختياريًا لحدود صوتية على مستوى المقاطع (`conda install -c conda-forge montreal-forced-aligner` ثم تنزيل النماذج والقواميس `arabic_mfa` / `english_us_arpa`). في أول تشغيل ينزّل التطبيق نموذج Whisper ‏`large-v3` (≈١٫٥ جيجابايت) مع شريط تقدّم داخل التطبيق.

## ٢. فحص العتاد

افتح تبويب **التشخيص** قبل أول مهمة. تقرأ اللوحة المعالج والذاكرة وكرت NVIDIA (عبر `nvidia-smi`). بوجود CUDA يعمل التفريغ بنموذج `large-v3` بدقة INT8-float16 على كرت الرسوميات؛ وبدونه يُظهر التطبيق تحذيرًا صريحًا بأن المعالجة ستعود إلى المعالج (INT8) وقد تستغرق ضعف الزمن الحقيقي تقريبًا. عشر دقائق من الصوت الإنجليزي تُنجَز في ≈١٥ دقيقة على RTX 3060. يمكنك أيضًا تثبيت الجهاز لكل مهمة من تبويب **الاستوديو** (تلقائي / معالج / كرت رسوميات).

## ٣. التسجيل والمعالجة (الخطوات الست)

1. من تبويب **الاستوديو**، أفلت ملفًا أو انقر منطقة الإفلات للاختيار؛ أو انقر **التسجيل من الميكروفون** لالتقاط الصوت المباشر (اضغط «إيقاف التسجيل» لرفع التسجيل).
2. اختر **اللغة**: الإنجليزية، أو العربية — المصرية (عامية)، أو العربية — الفصحى.
3. انقر **بدء المعالجة**. يُعرض التقدّم لكل مرحلة مباشرةً من طابور المهام المحلي:

| # | المرحلة | ما يحدث |
|---|---------|---------|
| ١ | **الإدخال والمعالجة المسبقة** | فكّ الحاوية إلى WAV أحادي ١٦ كيلوهرتز (PyAV/pydub) |
| ٢ | **التفريغ ASR** | faster-whisper ‏`large-v3` بدقة INT8؛ طوابع زمنية ودرجة ثقة لكل كلمة |
| ٣ | **المحاذاة القسرية** | تُدقّق MFA حدود الكلمات والمقاطع (عند تثبيتها) |
| ٤ | **السمات الإيقاعية** | Praat عبر ParSelmouth: النبرة الأساسية (٥٠–٤٠٠ هرتز)، الشدة، الجيتر، الشيمر، HNR |
| ٥ | **اضطرابات الكلام** | توقفات > ٢٠٠ ملي ثانية، حشو (يعني، آه، إيه، um، uh)، تكرار، بدايات خاطئة، مقاطعات، مدّ أصوات |
| ٦ | **المخرجات المنظمة** | SQLite (٣ جداول) + JSON + TEI/XML محليًا |

إذا لم يكن عامل بايثون مثبتًا، يعمل **محرك المحاكاة** بدلًا منه — نفس المراحل الست مع corpus تجريبي — مع وسم المهمة بـ«محاكاة» حتى لا تختلط البيانات التجريبية بالتفريغات الحقيقية.

## ٤. تصحيح التفريغ (محرر الثقة الملوّنة)

افتح تبويب **محرر التفريغ**. تحمل كل كلمة درجة ثقة ASR كلون خلفية: **أخضر ≥ ٠٫٨٥**، **كهرماني ٠٫٦٠–٠٫٨٥**، **أحمر < ٠٫٦٠** — ابدأ بمراجعة الكلمات الحمراء. انقر أي كلمة لتصحيحها: يحفظ التعديل ويوسم الكلمة بأنها «معدَّلة» ويُدرج الجملة في **إعادة محاذاة لهذه الجملة فقط**، فلا تُعالج الملفات كلها من جديد لإصلاح كلمة واحدة. تعرض كل جملة أيضًا الاضطرابات المكتشفة (عدد التوقفات، الحشو، التكرار، البدايات الخاطئة، المقاطعات، المدّ) وملخص الإيقاع (متوسط/أدنى/أقصى نبرة، الشدة، الجيتر، الشيمر، HNR).

## ٥. البيانات الوصفية للcorpus (ترويسة TEI)

من تبويب **بيانات الcorpus** صِف الجلسة: العنوان، اسم المتحدث أو اسمه المستعار، اللهجة، الجنس، العمر، تاريخ ومكان التسجيل، النوع، الرخصة، وملاحظات حرة. تُضمَّن هذه الحقول في `<teiHeader>` لكل تصدير TEI/XML، وهي نفسها الحقول التي يتوقعها CorpusMind عند الاستيراد — راجع فصل البيانات الوصفية في [موقع المشروع](https://waleedmandour.org/projects/CorpusMind/). تُدعم البيانات العربية بالكامل (تتحول الواجهة كلها إلى العربية من اليمين لليسار بخط Cairo عبر زر **العربية**).

## ٦. التصدير إلى CorpusMind

يكتب تبويب **التصدير** أربعة ملفات تُنشأ محليًا من مخزن الcorpus:

- **JSON** — سجلات كاملة؛ تُحمَّل مباشرةً بـ `pandas.json_normalize(corpus["utterances"], record_path="tokens")`.
- **CSV** — جدول كلمات مسطّح (رقم الجملة، رقم الكلمة، النص، البداية/النهاية بالمللي ثانية، الثقة، وسوم التعديل).
- **TEI/XML** — وثيقة TEI P5 مع ترويستك ووقت-aligned `<w>` لكل كلمة.
- **SQLite** — قاعدة ثلاثية الجداول مستقلة (`audio_metadata` و`utterances` و`tokens`).

على أي جهاز فيه CorpusMind مثبت، يفتح زر **تشغيل CorpusMind** في التشخيص التطبيق المكمّل مع هذا الcorpus جاهزًا للبحث — الكونكوردانس والتجميعات وقوائم الترددات كما في وثائق الموقع.

## ٧. المساعد الذكي المحلي (اختياري)

يتحدث تبويب **المساعد** مع نموذج Ollama محلي (`http://127.0.0.1:11434`) عن تفريغاتك — مثلًا: «اذكر الجمل التي فيها أكثر من كلمة حشو». شغّله مرة بأمر `ollama serve` ونزّل أي نموذج (`ollama run llama3.1`). إن لم يكن Ollama يعمل، تُخبرك اللوحة بذلك ولا تستعوض أبدًا بخدمة سحابية.

## ٨. حل المشكلات

| العَرَض | الحل |
|---------|------|
| المهمة موسومة «محاكاة» | عامل بايثون غير مثبت → `pip install -r python/requirements.txt` |
| «MFA skipped» في المرحلة ٣ | اختياري: ثبّت MFA والقواميس (انظر §١) |
| «لم يُكتشف كرت NVIDIA» | طبيعي على الأجهزة بلا كرت؛ يُستخدم وضع المعالج INT8 |
| زر الميكروفون لا يعمل | اسمح بالوصول للميكروفون من المتصفح أو ارفع ملفًا |
| المساعد يقول إن Ollama غير متاح | `ollama serve` ثم أعد فتح التبويب |
| تنزيل النموذج يتوقف | يستأنف تنزيل large-v3 تلقائيًا في المهمة التالية |
